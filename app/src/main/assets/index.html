Arena Connection

Windows PC log monitoring is unavailable on Android.

Android cannot access Arena Player.log on your Windows computer. Use desktop Arcane Vault to capture logs, then transfer saved decks and match history through backups/CSV. The tools below require the Windows host. Arena's current Player.log does not reliably contain your full owned-card collection. Your CSV remains the authoritative collection snapshot; this connector never overwrites it. Information below appears only when the log provides a recognizable event.

Connection settings

Enable Detailed Logs in Arena: Options → View Account → Detailed Logs, then restart Arena. The log is read locally by Arcane Vault's built-in C# service.

Official card data & art

Scryfall supplies card art, color identity, rarity, type lines, Oracle rules text, and all reported format legalities. Connect to the internet before syncing. The Android-local service requests Scryfall data and caches owned-card metadata and catalog records on your device. All Scryfall format statuses appear on each card detail view. Refresh format legalities periodically because bans and rotations change. The full printing catalog is downloaded by “Sync All Card Data”; it never alters ownership quantities. Arena filtering is based on Scryfall game availability, not on Arena cosmetics ownership. The app is unofficial and not affiliated with Wizards of the Coast or Scryfall.

How to search

Use the role chips for Ramp, Removal, Discard, Stax, Lifegain, Tutors, Haste, Protection, and other deckbuilding functions. These are assigned from official Oracle text using broad heuristics, so they're powerful browsing aids but not definitive rules judgments. Search also matches the full Oracle text after enrichment. Filtering on rarity, mana value, color identity, or types works best once card data is synced.

For split cards, double-faced cards, and specialized digital-only Arena variants, the name matching may occasionally select the wrong printing or miss a card. Check the displayed card face, set, and Scryfall link before crafting. Card ratings are not claimed.

Collection data protection

Android stores Arena and physical inventories in a single durable native location. Previously hidden collection data from older Android versions is recovered before opening the app. Only verified redundant legacy storage is removed; conflicting old snapshots are preserved rather than silently discarded.
