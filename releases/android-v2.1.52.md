# Arcane Vault Android v2.1.52

## Added
- Compact, clearly visible four-choice Arena peer conflict menu with current Android, Windows, baseline quantities and total number of differing records.
- Regression check preventing a long message panel from obscuring conflict choices on narrow Android screens.

## Changed
- Present conflict decisions in a list-only Android AlertDialog; choose one card or all shared Arena card differences directly.
- Keep separate final apply review, pre-sync recovery backup, live snapshot revalidation and all existing non-Arena merge safety checks.

## Fixed
- The previous modal combined a long message with selectable items, causing its four selection options to be hidden behind the message on Android phones.
- Removed literal newline-escape text from the dialog by removing the redundant long message.

## Removed
- Only the verbose, redundant dialog explanation; no collection, inventory, deck, artwork, peer checkpoint, or saved data removed.
