# Arcane Vault Android v2.0.4

## Added
- USB QR transfer support for Windows v5.21.0 using an authorized Android Debug Bridge (ADB) USB reverse connection.
- **Import sync JSON file** in Physical Collection to transfer data via ordinary USB file transfer, with no USB debugging or Wi-Fi required.
- Existing preview, explicit replacement scope, confirmation, and Undo functionality now work for USB JSON imports.

## Changed
- The Windows QR scanner accepts valid Arcane Vault loopback transfer links for wired USB connections as well as local Wi-Fi links.
- Physical Collection explains both USB methods.

## Fixed
- Windows-to-Android collection transfer no longer requires working Wi-Fi when a USB connection is available.

## Removed
- No features removed.
