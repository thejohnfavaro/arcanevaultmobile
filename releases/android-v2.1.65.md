# Arcane Vault Android v2.1.65

## Added
- Compact mobile catalog header with a direct Shortlist shortcut.
- Three persistent card browsing modes: card art grid, detailed list, and text-only list.
- Adjustable cards per page: 20, 40, or 80, remembered between sessions.

## Changed
- Consolidated catalog search and filters into a narrow toolbar.
- Moved collection scope into small Physical / Arena / All buttons.
- Collapsed mana color filters into an optional row, preventing them from obscuring catalog results.
- Remember the last catalog source, ownership scope, mana-color selection and view mode.
- Reduced extra card spacing and removed redundant catalog branding and duplicate top tabs.
- Kept search visible while scrolling through catalog results; advanced filters remain available from the search toolbar.

## Fixed
- Reclaimed vertical browsing space on Android and avoided controls overlapping card rows.
- Corrected filter drawer and header initialization after Android compiler verification.

## Removed
- Redundant full-size page heading and secondary navigation tabs on the Android catalog page.

Physical ownership, valuation, deck data, and sync semantics remain unchanged.
