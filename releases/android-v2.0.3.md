# Arcane Vault Android v2.0.3

## Added
- **Scan Windows QR** in Android's Physical Collection screen.
- Native Android QR scanning using the Google Code Scanner (Google Play services).
- Direct download of Windows' five-minute, one-time local-network collection transfer link.
- Manual transfer-link field for devices where camera scanning is unavailable.
- Preview and confirmation before replacing Physical, Arena, or both inventories.
- **Undo last QR import** to restore previous inventories.

## Changed
- QR transfers accept only the exact Arcane Vault LAN transfer URL format; remote URLs are rejected.
- Imported card printings and Arena quantities are kept distinct.

## Fixed
- Missing QR transfer option in the Android Physical Collection screen.

## Removed
- No features removed.
