# Arcane Vault Android — android-v2.0.23: Expanded Promotional Set Artwork

## Added
- Expanded Set Progress's curated promotional-art catalog to **38 set codes** across 18 artwork families, from Ikoria (2020) and older recent sets through Lorwyn Eclipsed (2026).
- Artwork mappings for main expansions, related Commander products and several associated bonus sheets when an appropriate parent-set promotional image exists.
- Distinct visuals for Bloomburrow, Duskmourn, Foundations, Outlaws of Thunder Junction, Murders at Karlov Manor, Ixalan, Wilds of Eldraine, Aetherdrift, Tarkir: Dragonstorm, Edge of Eternities, Dominaria United, The Brothers' War, Phyrexia: All Will Be One, Kamigawa: Neon Dynasty, Streets of New Capenna, Kaldheim, Ikoria, and Lorwyn Eclipsed.

## Changed
- Replace the earlier Bloomburrow artwork link with a published Wizards-hosted image URL.
- Prioritize official Wizards-hosted promotional imagery when a direct link is available; other curated images show Magic's official promo artwork served by external hosts.
- Continue loading set backgrounds lazily and preserve visible expansion symbols, dark contrast overlays, progress counts, the saved artwork preference and completed-set gold accent.

## Fixed
- Retain a representative Scryfall illustration if a promotional image is missing, blocked or offline, and the existing gradient if no artwork loads.

## Removed
- No existing features removed.

## Data safety
- No database schema, printing identity, collection ownership, set completion, pricing, or sync changes.
- No artwork binaries are bundled. Images are fetched from their listed hosts and are copyright Wizards of the Coast / respective artists. Arcane Vault remains unofficial fan content.
- This is a curated first wave, not a claim of official marketing-art coverage for every historical set. Other sets retain their representative card-art fallback.
