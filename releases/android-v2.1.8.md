# Arcane Vault Android v2.1.8 — organized Data & Sync workspace

## Added
- Four clear tabs inside the full-page native **Data & Sync** destination: Device Sync, Snapshots, Import & Export, and Updates.

## Changed
- Device Sync is the default, bringing wireless QR transfers, reviewed differential inventory changes, and three-way comparisons to the top instead of burying them below backup controls.
- All existing snapshots, recovery actions, catalog maintenance and signed update controls remain available in their dedicated sections.

## Fixed
- The long ungrouped Data & Sync action list no longer requires extensive scrolling to reach peer sync operations.

## Removed
- No existing functionality removed; navigation is reorganized only.

## Safety
- Existing sync review, baseline verification, inventory recovery and explicit approval remain unchanged. No collection data is migrated or rewritten as part of this UI update.
