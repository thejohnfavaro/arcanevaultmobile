# Arcane Vault Android v2.0.22 — Illustrated Set Progress

## Added
- Optional illustrated set tiles in Set Progress with a persisted **Show set artwork** preference.
- A curated official Bloomburrow promotional background for BLB/BLC, with lazy loading and a reusable mapping for future sets.
- Subtle gold framing for fully completed sets.

## Changed
- Keep each official expansion symbol visible and prominent over darkened illustrated tiles.
- Prioritize curated promotional art, then representative Scryfall art, then the existing plain gradient background.
- Respect reduced-motion accessibility preferences.

## Fixed
- Maintain readable set completion information and set-symbol fallback when art is missing or unavailable.

## Removed
- No features removed.

## Data safety
- No physical inventory, printing metadata, set completion, QR/USB/Wi-Fi sync or Arena collection changes.
- Artwork is remotely sourced rather than bundled; download still requires connectivity for uncached images. This is unofficial fan content, not endorsed by Wizards of the Coast.
- Other sets continue using representative card art until verified promotional images are curated.
