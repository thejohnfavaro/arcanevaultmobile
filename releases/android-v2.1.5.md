# Arcane Vault Android v2.1.5 — QR wireless reviewed inventory apply

## Added
- **Scan QR & apply Windows inventory** in native Data & Sync. Scan the one-time QR generated by Windows **Share Sync to Phone (Wi-Fi)**.
- Download the latest Windows peer snapshot over the existing bounded local Wi-Fi client and choose a previously shared baseline using Android's file picker.
- Reuse the Android three-way merge, explicit approval, recovery journal, optimistic inventory checks and undo controls for physical and Arena inventories.

## Changed
- QR scanning can now request a reviewed write-back flow instead of exclusively displaying a read-only comparison.
- Read-only scan/receive, existing file-based apply, backup and undo remain available.

## Fixed
- No need to manually export a Windows JSON file onto the phone before applying approved, non-conflicting inventory changes.

## Removed
- No existing features removed.

## Safety
- **No write is performed when scanning, downloading or receiving a QR link.** The user must select the actual previous common baseline, review and confirm.
- Android **still refuses deck/artwork write-back**, pending a reliable atomic WebView/local database transaction. Apply deck/artwork changes on Windows instead.
- Pairing, authenticated persistent shared checkpoints and full automatic sync are not yet implemented.
- QR/LAN transport uses HTTP and is not encrypted. Only use trusted home Wi-Fi; keep token URLs secret.
- Play Protect report #36 remains unresolved.
